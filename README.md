# Hotel Reservation Analysis Dashboard

## Introduction

This project presents an interactive **Power BI dashboard** built to analyze hotel reservation data and uncover booking patterns, cancellation behavior, and operational insights within the hospitality industry.

The dashboard is designed to support data-driven decision-making by helping hotels better understand guest behavior, reservation trends, and service performance.

---

## Project Overview

The analysis focuses on key hotel reservation metrics such as:

- Total bookings
- Reservation lead time
- Booking cancellations
- Room type preferences
- Meal plan selection
- Parking utilization
- Special guest requests
- Repeat guest behavior

These insights can help improve operations, customer satisfaction, and business planning.

---

## Dashboard Pages

### 1. Overview Dashboard

Provides a high-level summary of hotel reservation performance, including:

- Total bookings
- Monthly booking trends
- Average lead time
- Guest distribution over time

---

### 2. Cancellation Analysis

Focuses on cancellation behavior and booking drop-off trends.

Key insights include:

- Cancellation rate
- Relationship between lead time and cancellations
- Guest special request trends
- Reservation status distribution

---

### 3. Operational Insights

Provides visibility into customer preferences and operational planning metrics.

Includes analysis of:

- Preferred room types
- Meal plan demand
- Parking requirements
- Repeat vs new guest behavior

---

## Dataset

This project uses the **Hotel Reservation Dataset** from Kaggle.

The dataset includes reservation-level hotel booking information such as:

- Lead Time
- Booking Status
- Market Segment
- Room Type
- Meal Plan
- Special Requests
- Parking Space Required
- Repeated Guest Status

---

## Tools Used

- Power BI
- Power Query

- Microsoft Excel / CSV
- Data Cleaning & Transformation

---

## Key Insights

Some major insights from the analysis include:

- Certain booking channels generate higher reservation volume than others
- Longer lead times tend to correlate with increased cancellations
- Specific room types and meal plans are more frequently selected
- Returning guests show different booking behavior compared to first-time guests
- Operational planning can be improved using demand trends from the dashboard
